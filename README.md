# CalcoloRAL — Calcolatore RAL → Netto 2026

Calcolatore dello stipendio netto partendo dalla RAL (Reddito Annuo Lordo), aggiornato alla normativa fiscale italiana 2026.

## Funzionalità

- Calcolo netto annuale e mensile (12, 13, 14 mensilità)
- IRPEF 2026 con scaglioni 23% / 33% / 43% (L. 199/2025)
- Contributi INPS dipendenti (9,19% + 1% sopra €56.224)
- Detrazioni lavoro dipendente (Art. 13 TUIR)
- Bonus cuneo fiscale, ulteriore detrazione cuneo, trattamento integrativo
- Addizionali regionali progressive per regione
- Addizionali comunali per città
- Confronto tra 16 città italiane
- Dark mode

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- React Router

## Setup

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deployabile su Vercel con configurazione zero.
